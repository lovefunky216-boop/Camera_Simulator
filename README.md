# 📷 Hasselblad 907X & CFV 100C Virtual Shooting Experience
### 핫셀블라드 907X & CFV 100C 실감 촬영 시뮬레이터 🇸🇪

> **"유튜브 쇼츠처럼, 핫셀블라드 907X / 500C 카메라를 직접 두 손에 쥐고 웨이스트 레벨 틸트 화면으로 피사체를 조준하며 찰칵 찍어보는 짜릿한 손맛!"**  
> 전 세계 사진가들의 로망이자 1,500만원을 호가하는 핫셀블라드 중형 카메라(907X & CFV 100C)를 가상으로 완벽하게 체감할 수 있는 인터랙티브 촬영 시뮬레이터입니다.

---

## ✨ 새로운 핵심 기능 (Key Highlights)

### 1. 🎬 쇼츠 감성의 1인칭 웨이스트 레벨(POV) 촬영 모드
- [유튜브 쇼츠](https://youtube.com/shorts/BBdgyXQbLdY?si=MpYoFvkhDJi03QrG) 속 구도 그대로!
- 두 손으로 핫셀블라드 본체를 받쳐 들고, 위에서 40°로 젖혀진 틸트 LCD를 내려다보는 시점.
- 마우스나 스마트폰 기울기(자이로스코프)로 카메라를 들고 세상을 둘러보며 프레이밍.
- 렌즈 포커스 링을 마우스 휠이나 슬라이더로 돌려 수동 초점을 맞추는 **Manual Focus & Peaking** 손맛.
- 우측 하단의 오렌지 'H' 셔터 버튼을 누르면:
  - 찰-칵! 하는 리프 셔터음과 함께 순간 플래시 & 암전
  - 틸트 화면이 즉시 방금 찍은 사진을 보여주는 **리뷰(Play) 모드**로 전환!
  - 핫셀블라드 공식 스타일 액자 카드로 저장 가능.

### 2. 🧊 3D 인터랙티브 카메라 외형 스튜디오 (Three.js PBR)
- 핫셀블라드 스웨디시 정밀 크롬 엣지, 블랙 가죽 스킨, 널링 렌즈를 360도로 자유롭게 돌려보기.
- **물리 틸트 스크린 힌지 조작**:
  - `0°` (접힘)
  - `40°` (아이코닉 웨이스트 레벨 틸트)
  - `90°` (탑다운 수직 촬영 앵글)
- 3D 카메라 틸트 화면 표면에도 실시간으로 뷰파인더 영상이 투영됨.

### 3. 🔄 카메라 모델 스위처 (Modern vs Vintage)
- **907X & CFV 100C**: 컴팩트한 모던 중형 미러리스 셋업 (XCD 38V 렌즈)
- **500C/M & CFV 100C**: 전설적인 아날로그 500C/M 바디 + 접이식 4단 메탈 차광판 후드 + 1:1 정방형 포맷

### 4. 📹 웹캠 라이브 패스스루 (Live Real-World Shooting!)
- 웹캠을 허용하면 **내 방이나 앞의 실제 풍경이 핫셀블라드 907X 틸트 화면 속에 실시간으로 비침**!
- 진짜 카메라를 손에 쥔 것처럼 내 주변의 피사체를 조준하고 찰칵 촬영 가능.
- 고대 신전 회랑(Temple of Columns), 도심 골든아워, 스튜디오 씬 기본 내장.

### 5. 🔊 Web Audio 기반 리프 셔터 & 미러 메카니즘
- 907X XCD 렌즈의 정숙하고 묵직한 솔레노이드 리프 셔터 사운드
- 500C/M의 클래식한 대형 미러 플랩 사운드
- 금속 널링 휠 다이얼 클릭음 및 모바일 햅틱 진동

## 🚀 빠른 시작 (Quick Start)

```bash
# 1. 저장소 클론
git clone https://github.com/lovefunky216-boop/Camera_Simulator.git

# 2. 디렉토리 이동
cd Camera_Simulator

# 3. 브라우저에서 index.html 바로 열기 (또는 로컬 서버)
python -m http.server 8000
```
브라우저에서 `http://localhost:8000`으로 접속하여 핫셀블라드의 손맛을 즐겨보세요!
