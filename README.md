# 📷 Southern Italy on Film | Hasselblad 503CX
### 핫셀블라드 503CX 감성 아날로그 필름 시뮬레이터 🇮🇹

> **"유튜브 쇼츠([https://www.youtube.com/shorts/vPh_jMKVl1M](https://www.youtube.com/shorts/vPh_jMKVl1M)) 속 그 감성 그대로!"**  
> 1. 닫혀있는 핫셀블라드 503CX 뚜껑을 탭하면  
> 2. "철컥" 소리와 함께 후드가 열리며 남부 이탈리아 풍경이 그라운드 글래스에 비치고  
> 3. 셔터를 누르면 묵직한 아날로그 셔터음과 함께 찰칵!  
> 4. 인화된 6x6 정방형 필름 사진이 나타나며 자유롭게 확대/축소할 수 있는 초심플 감성 시뮬레이터입니다.

---

## ✨ 직관적인 4단계 경험

1. **카메라 뚜껑 열기 (Tap to Open)**
   - 닫힌 503CX 웨이스트 레벨 파인더 뚜껑을 클릭하면 기계식 래치 소리와 함께 접이식 메탈 차광판 후드가 촥 펼쳐집니다.
2. **뷰파인더 속 남부 이탈리아 풍경 감상**
   - 6x6 그라운드 글래스 매트 스크린과 클래식 십자 격자선 안에 지중해의 따스한 햇살과 바다 풍경이 맺힙니다.
3. **셔터 누르기 (찰-칵! 철컥!)**
   - 전면 크롬 셔터 버튼(또는 스페이스바)을 누르면 거대한 미러가 튕기는 묵직한 아날로그 셔터음과 함께 촬영됩니다.
4. **120 중형 필름 사진 & 무한 딥 줌**
   - 방금 촬영된 6x6 중형 필름 사진이 화면에 떠오르며, 마우스 휠이나 핀치 줌으로 세부 디테일을 자유롭게 확대/축소할 수 있습니다.
   - 하단 버튼: `[ ↺ 뚜껑 닫고 다시 찍기 ]`

## 🚀 빠른 시작 (Quick Start)

```bash
# 1. 저장소 클론
git clone https://github.com/lovefunky216-boop/Camera_Simulator.git

# 2. 디렉토리 이동
cd Camera_Simulator

# 3. 브라우저에서 index.html 바로 열기 (또는 로컬 서버)
python -m http.server 8000
```
브라우저에서 `http://localhost:8000`으로 접속하여 핫셀블라드의 손맛을 즐겨보세요!
