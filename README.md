# 📷 Hasselblad 100MP YouTube Shorts Exact Flow Simulator
### 핫셀블라드 100MP 유튜브 쇼츠 완전 복제 시뮬레이터 🇸🇪

> **"유튜브 쇼츠 영상([https://www.youtube.com/shorts/BBdgyXQbLdY](https://www.youtube.com/shorts/BBdgyXQbLdY))과 완전히 똑같은 순서와 연출!"**  
> 1. 전체 풍경이 펼쳐지고  
> 2. 그 앞에 핫셀블라드 907X 카메라가 나와 틸트 화면으로 조준하고  
> 3. 셔터를 "찰칵!" 누르면  
> 4. 1억 화소 원본 전체 사진이 나타나고  
> 5. 스르륵... 극소 디테일로 파고들며 1억 화소의 충격적인 해상력이 드러나는 시네마틱 인터랙티브 웹 시뮬레이터입니다.

---

## 🎬 쇼츠와 100% 동일한 5단계 시퀀스

1. **STEP 1 : 전체 풍경 & 카메라 조준**
   - 화면에 1억 4천만 화소 피렌체 대성당 광장(또는 대전당 돔) 전체 풍경이 시원하게 펼쳐집니다.
   - 전면에 핫셀블라드 907X & CFV 100C 카메라가 자리잡고 있으며, 40° 틸트 LCD 스크린 속에 바깥 풍경이 실시간으로 비칩니다.
2. **STEP 2 : 찰칵! 셔터 누르기**
   - 오렌지 셔터 버튼(또는 스페이스바)을 누르면 실제 핫셀블라드 XCD 렌즈의 "착-츳" 리프 셔터음과 함께 순간 플래시 & 암전 효과가 작동합니다.
3. **STEP 3 : 1억 화소 전체 원본 사진 공개**
   - 카메라가 슥 내려가며, 방금 찍힌 초고화질 전체 사진(13,920 × 10,200)이 화면 가득 나타납니다.
4. **STEP 4 : 충격의 100MP 딥 줌 (The Viral Super-Zoom Reveal)**
   - 쇼츠 영상처럼 30배율로 부드럽게 스르륵... 줌인되며, 수백 미터 밖 꼭대기 돔 랜턴의 구리 리벳과 금박 질감이 1:1 픽셀 단위로 선명하게 공개됩니다!
   - 우측 하단에 전체 사진 대비 어디를 확대한 것인지 보여주는 **PIP 미니맵**이 작동합니다.
5. **STEP 5 : 자유 탐색 & 다른 장소 촬영**
   - 마우스 휠로 다른 곳도 자유롭게 무한 딥 줌 탐색 가능.
   - `[ ↺ 다른 장소에서 또 찍기 ]` 버튼으로 처음부터 다시 촬영 가능.

## 🚀 빠른 시작 (Quick Start)

```bash
# 1. 저장소 클론
git clone https://github.com/lovefunky216-boop/Camera_Simulator.git

# 2. 디렉토리 이동
cd Camera_Simulator

# 3. 브라우저에서 index.html 바로 열기 (또는 로컬 서버)
python -m http.server 8000
```
브라우저에서 `http://localhost:8000`으로 접속하여 핫셀블라드의 손맛을 즐겨보세요!
